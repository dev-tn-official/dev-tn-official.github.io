Software Design and Engineering

Travlr Getaways — Authenticated Delete Functionality

For the Software Design and Engineering enhancement, I expanded the administrative functionality of the Travlr Getaways full-stack application by implementing the missing delete operation needed to complete its CRUD capabilities. The enhancement allows an authenticated administrator to delete an existing trip through the Angular interface while requiring confirmation before the request is submitted.

The enhancement extends across multiple layers of the MEAN application, including the Angular components and data service, Express API, JWT authentication middleware, Mongoose controller, and MongoDB database. Authentication is enforced by the backend DELETE route rather than relying only on the visibility of the user-interface controls. The completed feature was tested through both Postman and the Angular interface using valid, invalid, and missing authentication as well as successful, cancelled, and unsuccessful deletion attempts.
