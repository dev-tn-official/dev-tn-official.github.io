Software Design and Engineering

Travlr Getaways — Authenticated Delete Functionality

For the Software Design and Engineering enhancement, I expanded the administrative functionality of the Travlr Getaways full-stack application by implementing the missing delete operation needed to complete its CRUD capabilities. The enhancement allows an authenticated administrator to delete an existing trip through the Angular interface while requiring confirmation before the request is submitted.

The enhancement extends across multiple layers of the MEAN application, including the Angular components and data service, Express API, JWT authentication middleware, Mongoose controller, and MongoDB database. Authentication is enforced by the backend DELETE route rather than relying only on the visibility of the user-interface controls. The completed feature was tested through both Postman and the Angular interface using valid, invalid, and missing authentication as well as successful, cancelled, and unsuccessful deletion attempts.

Algorithms and Data Structures

Travlr Getaways — Trip Searching and Sorting

For the Algorithms and Data Structures enhancement, I expanded the administrative functionality of the Travlr Getaways full-stack application by implementing client-side searching and sorting capabilities for trip records. These features allow administrators to locate and organize trips more efficiently without manually reviewing the entire collection.

The enhancement introduces case-insensitive searching across trip names, resort names, and trip codes, along with sorting options based on trip name, price, and start date. The implementation maintains a separate displayed collection so filtering and sorting operations do not modify the original dataset. Numeric price conversion and date comparisons help ensure that records are sorted according to their values rather than simply their text representations.

This enhancement demonstrates how algorithms and data structures can improve the usability of a data-driven application while considering data integrity, performance, and maintainability.

Databases

Travlr Getaways — Database Validation and Integrity

For the Databases enhancement, I strengthened the data integrity and reliability of the Travlr Getaways full-stack application by improving its MongoDB and Mongoose implementation. The enhancement focuses on schema validation, database indexing, and more reliable record retrieval and update operations.

The enhancement introduces stronger validation for trip records, including trimming string values, normalizing trip codes, and validating price information. A unique index prevents duplicate trip codes, while an unnecessary index on trip names was removed. I also replaced the individual-trip lookup using find() with findOne() to retrieve a single matching document and provide more accurate handling when a trip does not exist.

Additional improvements ensure that schema validation is enforced during updates and that administrators receive useful error messages when database operations fail. The editing process was also adjusted to preserve the original trip code when identifying a record, allowing proposed code changes to be checked correctly against the database's uniqueness constraint.

This enhancement demonstrates the importance of database constraints, consistent validation, and reliable communication between the database, API, and administrative interface. Together, these changes improve data integrity and maintainability while preserving the existing MEAN-stack application architecture.
